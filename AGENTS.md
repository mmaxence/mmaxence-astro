# Portfolio design rules

- Do not add northeast arrows (U+2197), diagonal external-link icons, or equivalent SVG decorations to links. Use the link label itself. This applies to shared components, page content, and design specimens.

- Do not use em dashes (U+2014), including encoded forms, in website content. This covers headings, body copy, captions, image descriptions, UI labels, metadata, feeds, AI-readable exports and displayed code examples. Use commas, colons, parentheses or separate sentences as appropriate. Do not substitute en dashes or double hyphens as sentence punctuation. Ordinary hyphens and date or number ranges are fine.

- Write portfolio copy for readers with no company context. Explain unfamiliar product names and acronyms on first use. Keep captions editorial: omit capture dates, build versions and audit-style provenance unless they change the reader’s understanding. Keep meaningful dates, source links, live/prototype distinctions and limitations needed to interpret results.

- Prefer “campaigns” in portfolio narratives when describing brand experiences and initiatives. Keep “ads” where it precisely names an ad unit, placement, source quotation or metric; do not change what a measured figure counts.
